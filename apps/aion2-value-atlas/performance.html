Interpretation and cautions

    Repeatable A/B/A troubleshooting

    1. Use the same location, character, camera rotation and graphics preset. Note your FPS overlay source, Reflex, V-Sync, G-SYNC/FreeSync and renderer, without changing everything together.
    2. Observe Fixed 6×, then temporarily compare FG Off → 2× → 6× in the same location. Look for hair trails, ghosting, shimmering UI and responsiveness; compare true frame times if supported.
    3. If comparing 240 Hz and 144 Hz screens, keep one common rendering resolution and repeat built-in → external → built-in. A 144 Hz display cannot show 240 distinct refreshes per second.
    4. If an RTX 50-series Laptop GPU crashes with G-SYNC and FG, refer to the NCSOFT-specific workaround. Do not enable unstable combinations solely for benchmarking.

    No live measurement of game frames, real latency, panel processing or effective G-SYNC is performed here. No driver or game setting is changed or saved.
